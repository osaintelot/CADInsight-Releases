# CAD Insight releases

Finished app and firmware files for the CAD Insight GPS performance timer. The CAD Insight app checks `latest.json` here and offers updates.

- `app/`: Android app (`.apk`)
- `firmware/`: device firmware (`.bin`), installed from the app over Wi-Fi
- `latest.json`: the newest versions, their files and fingerprints (SHA-256)

Install the app on Android 10 or newer by opening the `.apk` on your phone.

This repository holds published files only. Source code is kept elsewhere.
